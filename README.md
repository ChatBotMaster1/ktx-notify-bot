# KTX 알림봇

매진 구간의 빈자리와 예매 오픈 시점을 텔레그램으로 알려주는 봇. **조회·알림만 하고, 예매는 직접 한다.**

## 현재 상태

| 기능 | 상태 |
|---|---|
| 텔레그램 명령어 등록/목록/삭제 | 동작 |
| 예매 오픈 알림 (승차일 1개월 전 07:00) | 동작 — 코레일 조회 없이 날짜 계산만 함 |
| 빈자리 감지 | **꺼둠** — 공개 `korail2` 0.4.0은 코레일 매크로 차단(`MACRO ERROR`)에 걸림 |

매진 열차는 코레일톡 **예약대기**(출발 2일 전까지 신청, 빈자리 생기면 자동 배정)를 쓴다.
빈자리 감지는 `main.py`의 `CHECK_SEATS = False`를 `True`로 바꾸면 다시 켜진다. 켜면 코레일에 조회를 보내므로 차단이 풀렸는지 먼저 확인할 것.

## 명령어

```
/등록 서울 부산 20260920 0900-1200 일반실
/목록
/삭제 번호
```

- 시간대: 출발 시각 기준 `HHMM-HHMM`
- 좌석: `일반실` 또는 `특실`
- 날짜 범위가 필요하면 날짜마다 따로 등록
- 지난 날짜의 조건은 자동 삭제

## 설정 순서

### 1. 텔레그램 봇 만들기
1. 텔레그램에서 `@BotFather` 검색 → 대화 시작 → `/newbot` 입력
2. 봇 이름, 아이디(끝이 `bot`) 입력
3. `123456789:ABC...` 형태의 토큰이 오면 성공 → **토큰은 남에게 보이지 않게 보관**

### 2. 내 채팅 ID 확인
1. 방금 만든 봇에게 아무 메시지나 보내기
2. 브라우저 주소창에 `https://api.telegram.org/bot<토큰>/getUpdates` 입력
3. 화면에서 `"chat":{"id":123456789` 부분의 숫자가 채팅 ID

### 3. GitHub 저장소 만들기
- **Public 저장소 권장**: Private은 무료 실행 시간이 월 2,000분이라 5분마다 돌리면 초과함
- Public이면 `data.json`(등록한 구간·날짜)이 공개됨. 토큰·채팅 ID는 들어가지 않음
- 이 폴더 전체를 올리되 `.env`, `.venv`는 제외(`.gitignore`에 이미 적혀 있음)

### 4. Secrets 등록
저장소 → Settings → Secrets and variables → Actions → New repository secret

| 이름 | 값 |
|---|---|
| `TELEGRAM_BOT_TOKEN` | 1번의 토큰 |
| `TELEGRAM_CHAT_ID` | 2번의 숫자 |

### 5. 첫 실행
저장소 → Actions → `KTX 알림` → Run workflow. 초록 체크가 뜨면 성공.
이후 봇에게 `/목록`을 보내고 5~10분 안에 답이 오면 자동 실행도 정상.

## 주의
- 실행 주기는 5분(GitHub 최소값). 실제로는 몇 분씩 밀릴 수 있어서 명령어 답장도 늦게 온다.
- 한 번 실행에서 조건 사이에 1초씩 쉰다. 주기를 더 짧게 바꾸지 말 것(계정·IP 차단 위험).
- 자동 예매/결제 기능은 넣지 않는다.
